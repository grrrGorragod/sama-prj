# Image prompts

Tool: built-in imagegen. Each asset used the common prompt plus its subject prompt, with the approved nine-card stick-figure concept and website mockup as visual references. Opaque backgrounds.

The requested size in the prompt was 1800 × 800; actual output is consistently 1881 × 836, also 9:4.

## Common prompt

Extract and adapt ONE specific illustration into a clean standalone image asset for a website card banner, not an interface mockup. Reference images show the approved SAMA minimalist stick-figure art style. Output exactly ONE edge-to-edge wide rectangular landscape background, 1800 by 800 pixels, aspect 9:4. No rounded border, no white card footer, no margin outside the image, no frame or shadow. Absolutely NO words, letters, numbers, percent signs, progress badges, capsules, pills, UI controls, logos, watermarks or labels anywhere. Completely remove all progress and text from the reference, replacing those regions with continuous clean pastel background. Use single-stroke stick figures with empty circular heads, thin rounded dark indigo lines, no faces, hair or clothing detail. Cohesive simple professional instructional pictogram aesthetic, not full-body cartoons. Uniform clean strokes and minimal props. Gentle pastel background gradient with a calm top-left zone covering x=0..42% and y=0..30%; leave it empty so the web developer can overlay live UI later. Main scene lower middle/right with generous safe margins around all figures and props, no clipping. Few quiet environmental details. Use the references only for illustration style and the indicated subject; do NOT reproduce a grid or an entire web page.
