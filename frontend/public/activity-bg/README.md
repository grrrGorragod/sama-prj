## การใช้บนเว็บ

นำภาพไปไว้ในโฟลเดอร์ public ของเว็บ แล้วใช้เป็นภาพส่วนบนของการ์ดเดิม
ชื่อกิจกรรม ป้ายเปอร์เซ็นต์ และสถานะให้เป็น HTML แยกจากภาพ เพื่อเปลี่ยนตามข้อมูลจริง

ตัวอย่าง CSS สำหรับองค์ประกอบ img ภายในแถบภาพเดิม:

```css
.activity-card-art {
  position: relative;
  overflow: hidden;
  aspect-ratio: 9 / 4;
}
.activity-card-art > img {
  display: block;
  width: 100%;
  height: 100%;
  object-fit: cover;
  object-position: center center;
}
.activity-card-progress {
  position: absolute;
  top: 14px;
  left: 14px;
}
```

หากกรอบภาพของเว็บสูงหรือแคบกว่าสัดส่วน 9:4 ให้ตรวจการครอปบนมือถือด้วย
สามารถเริ่มปรับ object-position เป็น center bottom เพื่อรักษาภาพคนและอุปกรณ์ด้านล่าง
ชื่อ class ในตัวอย่างเป็นตัวอย่าง ให้จับคู่กับ class ของเว็บเพื่อน
